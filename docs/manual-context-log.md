# Ручной контекст от пользователя

Дата: 2026-05-18

Этот файл хранит сжатые выводы из длинных пользовательских сообщений, чтобы не терять продуктовые решения между этапами разработки.

## Home после авторизации

- Первый экран уже сделан как landing.
- После успешной авторизации нужен Home, похожий по роли на Partiful welcome.
- На Home должны быть события пользователя: текущие, будущие, прошедшие.
- Должна быть кнопка создания события.
- Должна быть иконка профиля с минимальными настройками.
- Должна быть плашка уведомлений.
- Встроенные личные сообщения не нужны.

## Приватность

- В MVP все события приватные.
- Вход в событие по ссылке/QR.
- Публичные события и публичная афиша не нужны.
- Организатор может разрешить или запретить гостям приглашать других гостей.

## Галерея

- Галерея должна быть на Home, а не обязательно отдельной вкладкой.
- Основной режим: последовательные карточки событий.
- Каждая карточка события может раскрыться до фотографий, сохраненных пользователем из общего альбома этого события.
- Есть кнопка `Раскрыть все фото`, которая раскрывает все события и превращает экран в фотоленту.
- Даже в режиме фотоленты фото должны быть визуально привязаны к своим событиям.
- При открытии фото фон экрана должен соответствовать событию.
- При переходе между фото разных событий фон меняется.

## Оплата

- Реальных переводов внутри приложения нет.
- Приложение не проверяет факт оплаты.
- Организатор только указывает сумму и реквизиты/инструкцию.
- Участник сам нажимает `Оплатил` или `Оплачу позже`.
- Организатор видит простую статистику отметок.

## Достижения

- Достижений не должно быть слишком много.
- Основные достижения для MVP: автоматические.
- Автоматические достижения можно включать/отключать для события.
- Автоматические достижения выглядят как личные медальки.
- Отдельно можно создавать кастомные личные и групповые достижения.
- Личное достижение вручается конкретному гостю.
- Групповое достижение вручается всему событию.
- Визуально разделять автоматические и личные не нужно.
- Групповые достижения стоит показывать отдельно и выше личных.
